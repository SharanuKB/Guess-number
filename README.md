# 🎯 Guess the Number Game

A simple and fun **Guess the Number** game built using **HTML, CSS, and python**.

## 🚀 Features

* 🎲 Random number generation
* 🔢 User can enter a guess
* ⬆️ Shows whether the guess is too high
* ⬇️ Shows whether the guess is too low
* ✅ Displays the correct answer when guessed
* 🔄 Restart/New Game option
* 📱 Responsive and modern design

## 🛠️ Technologies Used

* HTML5
* CSS3
* python

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a number and try to guess the secret number.

## 🎮 How to Play

1. The computer generates a random number.
2. Enter your guess in the input box.
3. Click the **Guess** button.
4. Follow the hints:

   * **Too High** ⬆️
   * **Too Low** ⬇️
   * **Correct!** 🎉
5. Try to guess the number in as few attempts as possible.
